# 远程识别功能说明

## 用户入口

进入“幻影”后先选择角色。

### 识别端（手机1）

识别端保留原来的方案列表、识别界面和黑屏功能。进入识别页即自动连接功能设置中选定的大陆或新加坡服务器，不再提供远程连接开关。本机和本机连接的耳机都不播放提示音或报牌 TTS，时间模式固定为“无”，并隐藏本地识别结果入口。功能设置中不显示远程连接、音量、语速、播放设备和时间模式，但仍可选服务器。

### 接收端（手机2）

连接页只包含服务器、手机1序列号和“开始连接”。服务器与目标手机1都在线且该接收端名额可用时进入接收界面。默认显示手机1的 720p30 实时画面，并可切换黑屏、时间、当前识别结果和实时画面。

结果页与手机1使用同一个展示组件。手机2不运行识别和规则计算，收到什么快照就显示什么快照。

## 自动与手动信息

手机1可产生开始、成功、失败提示和最终识别结果。桌面端能控制“自动转发到手机2”：

- 开：手机2接收新的提示与结果，刷新 UI，并按手机1传来的文字、男女声意图、语速、重复次数播放。
- 关：服务器不向手机2发送任何自动信息；UI、牌组和声音都保持不变。

桌面手动发送的文字、成功/失败提示或完整当前/历史结果不受该开关影响。

## 播放冲突

同一次识别里的提示和报牌按顺序播放。新的识别操作会清空旧操作正在播放及等待播放的内容；新的桌面手动命令也会立即清空当前和等待内容。结果 UI 的刷新不等待声音播放完成。

## 连接与区域

- 大陆与新加坡服务器完全隔离；在一个区域上线的手机1不能被另一区域的手机2或桌面端看到。
- 当前权限规则是“知道手机1当前序列号即可监听”，没有额外配对或账号验证。
- 每个手机1在同一区域最多一个手机2和一个桌面端。
- 三端自动断线重连；短时掉线保留角色名额，其他设备不能趁断线占用。手机2租约期内未确认的最新命令会在重连后补发，已收到的序号不会重复播放。

## 视频和网络预期

视频固定 1280×720、30fps。无人观看时手机1停止发布媒体；有人切回画面时再恢复。视频采用 WebRTC/LiveKit。当前写死 IP 的测试环境使用 HTTP/WS；绑定域名后再切换到 HTTPS/WSS 和 TURN/TLS。

新加坡线路对大陆无 VPN 的可用性和抖动不能仅靠代码保证；大陆测试应优先选择大陆服务器。大陆桌面通过 VPN 连接新加坡时取决于 VPN 线路质量。TURN 能提高复杂 NAT/受限网络下的成功率，但也需要分别部署、监控和压测。
